# AI-Powered HRMS Backend (Python)

A comprehensive backend for a Human Resource Management System featuring AI-driven 
insights for resume screening, employee performance, and sentiment analysis.

## ✨ Key Features
- **Smart Recruitment:** AI-based resume parsing and candidate ranking.
- **Predictive Analytics:** Flight risk (attrition) prediction using ML models.
- **Employee Sentiment:** Natural Language Processing (NLP) to analyze employee feedback.
- **Automated Operations:** Smart leave management and attendance tracking.

## 🛠 Tech Stack
- **Backend:** Python (FastAPI/Django/Flask)
- **AI/ML:** Scikit-learn, TensorFlow, or PyTorch for predictive models
- **NLP:** HuggingFace or NLTK for sentiment and resume parsing
- **Database:** PostgreSQL (with pgvector for AI embeddings if applicable)
- **Task Queue:** Celery/Redis (for long-running AI training/inference)
